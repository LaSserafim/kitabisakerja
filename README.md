# KitabisaKerja.id

> **Indonesia's Dedicated Early-Career & Youth Opportunity Network**  
> Connecting university students, vocational graduates, and early professionals with verified internships, apprenticeships, and entry-level positions in Semarang, Central Java and remote.

---

## 🎯 Key Features

- **Verified Opportunity Catalog:** Screened entry-level roles and internships with zero recruitment fees and transparent compensation.
- **Institutional ATS Resume Engine:** Clean single-column machine-readable CV builder with dynamic scoring and direct PDF export.
- **Enterprise Employer Pipeline:** Direct talent acquisition portal for companies to post verified roles and screen motivated youth candidates.
- **Semarang & Remote Focus:** Regional employment hub based in Semarang, Central Java, connecting local businesses with emerging talent.
- **Interactive UI with Framer Motion:** Fluid scroll reveals, spring physics, dynamic navbar highlighting, and responsive mobile drawer.

## 🚀 Quick Start (Local Development)

Run locally using Python's built-in HTTP server:

```bash
python3 -m http.server 3000
```

Then open [http://localhost:3000](http://localhost:3000) in your web browser.

## ⚖️ Legal & Compliance

- **Zero-Fee Policy:** Strict compliance with Indonesian Manpower Law No. 13/2003 prohibiting fees from jobseekers.
- **Privacy Standard:** Personal candidate data protected in accordance with Indonesian Personal Data Protection regulations (UU PDP No. 27/2022).
- **Headquarters:** Semarang, Central Java, Indonesia.
